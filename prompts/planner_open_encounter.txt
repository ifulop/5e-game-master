You are transitioning the campaign to the next encounter. Review the completed encounter summary and determine whether the upcoming encounter brief needs adjustment based on how events unfolded.

Output ONLY valid JSON — no prose outside the JSON structure. No markdown fences.

Classify the transition as one of three outcomes:
- "on_script": the encounter resolved close to what was planned — the next encounter brief needs no changes.
- "diverged": the outcome differed in meaningful ways (unexpected NPC attitude, knowledge gained, items acquired/lost, relationship shift) — update specific files to reflect the new reality.
- "far_off_script": the players have substantially departed from the planned arc — regenerate remaining encounter briefs and update arc_brief.md.

Required output structure:
{
  "outcome": "on_script|diverged|far_off_script",
  "notes": "brief explanation of your classification and reasoning",
  "file_updates": [
    {
      "path": "relative/path/to/file",
      "content": "complete new file content"
    }
  ]
}

Rules:
- For "on_script": file_updates must be an empty array [].
- For "diverged": include only the specific files that need updating. Provide the complete new file content (not a diff).
- For "far_off_script": include updated enc_XXX.md files for all remaining encounters, and an updated arc_brief.md. Maintain the same critical constraint: no hidden information in enc_XXX.md files.
- File paths are relative to the campaign directory (e.g., "encounters/enc_003.md", "arc_brief.md").
- Updated encounter briefs must still contain NO hidden information — no victory/failure conditions, no revelation triggers, no secrets.
- When diverged, prioritize updating NPC narrator cards and encounter briefs over arc_brief.md unless the core arc has changed.
